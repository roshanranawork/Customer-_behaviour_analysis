# Customer-_behaviour_analysis
An end-to-end data analysis project exploring shopping behavior across 3,900 customer transactions, using Python and SQL to uncover patterns in spending, segmentation, and subscription behavior.
Data Analytics Project

A complete end-to-end Data Analytics Project demonstrating the data analysis workflow using Python, SQL, Power BI, and Gamma. This project covers data loading, exploratory data analysis (EDA), data cleaning, SQL querying, dashboard creation, report generation, and presentation preparation.

📌 Project Overview

The objective of this project is to analyze a dataset, extract meaningful insights, and present the findings through interactive dashboards and reports.

The workflow includes:

Loading and exploring the dataset using Python
Performing data cleaning and preprocessing
Conducting Exploratory Data Analysis (EDA)
Running SQL queries for business insights
Building an interactive Power BI dashboard
Preparing a detailed analytical report
Creating a professional presentation using Gamma
